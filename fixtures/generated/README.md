# Generated-page fixtures

Pages agents actually produced through the governed pipeline, kept as
golden examples. `signal-growth-cohere.html` is the reference for chart
quality: honest SVG charts with per-point accessibility, captions that
state what the data shows, tokens as CSS variables, reduced-motion
support, and the chart discipline (darkest series carries the story)
expressed in a captured system. The chart snippets in
`src/lib/graphics/kit.ts` are distilled from it.
