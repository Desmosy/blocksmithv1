# Design markdown sources

Drop any `.md` file here. BlockSmith will load it from the wiki **Design doc** dropdown.

| Parser | When |
|--------|------|
| **apollo** | Structured design system (color token tables, `## Components`, etc.) |
| **generic** | Any other markdown — one wiki page per `##` heading |

Example: `apollo.md` uses the full wiki UI. Add `my-product.md` to try generic mode.
